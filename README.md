# K-Timetable

A simple web application that allows students to **check their class schedule using their roll number and selected day**.

The project uses **Python for processing timetable Excel files** and a **web interface (HTML, CSS, JavaScript)** for easy access to class schedules.

---

## 🚀 Features

- 🔎 Search timetable using **Roll Number**
- 📆 Select **Day of the Week**
- ⚡ Instantly view scheduled classes
- 🌙 **Dark / Light Mode Toggle**
- 📊 Timetable generated automatically from Excel data

---

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend / Data Processing
- Python
- Pandas
- Excel
---

## ⚙️ How It Works

1. Raw timetable data is stored in **Excel sheets**.
2. Python scripts process and merge:
   - Core timetable
   - PE1 timetable
   - PE2 timetable
3. The processed dataset is used by **JavaScript**.
4. Users enter:
   - **Roll Number**
   - **Day**
5. The website displays the **class schedule for that day**.
